## 一句話

Markdown 不是醜，它只是還沒被打開 —— 你要的其實只有一句話：「請你輸出 HTML 格式讓我看」。

## 三分鐘講稿

你有沒有遇過，叫 AI 幫你整理一份報表，結果它吐給你一堆長這樣的東西：井字號、星號、一槓一槓的表格線…你看了頭很痛，覺得「這什麼鬼，好醜」。

那個東西叫 **markdown**。我要幫它平反一下 —— **markdown 不醜，它只是一種格式，你需要一個 reader 才能把它變漂亮。**

這件事跟 PDF 一模一樣。你想想，一個 PDF 檔本身也是一堆看不懂的編碼，你之所以覺得 PDF 很整齊漂亮，是因為你用 **PDF reader** 打開它。沒有 reader，PDF 也是天書。Markdown 也是同樣的道理 —— 它需要一個 markdown reader 幫你「渲染」出來，才會變成漂亮的標題、清單、表格。

順帶一提，很多地方其實已經內建這種 reader 了。比如 **Google Doc**，你把 markdown 直接貼進去，它會自動幫你整理成漂亮的格式。所以 markdown 不是沒用，是你得知道去哪裡打開它。

但我知道，對醫師團隊來說，你根本不想搞懂什麼 reader、什麼渲染。沒關係，你只要記住一句話就好，這句話解決一切：

**「請你輸出 HTML 格式讓我看。」**

為什麼是 HTML？因為你的瀏覽器天生就是最好的 reader。AI 輸出 HTML，你用瀏覽器一開，直接就是漂亮的排版、表格、顏色 —— 不用裝任何東西、不用懂任何技術。一句話，天書變報表。

所以下次 AI 給你一坨看起來很亂的東西，別皺眉頭，別覺得它做錯了。你就補一句：「請你輸出 HTML 格式讓我看」。就這樣。

## 關鍵重點

- Markdown 不是醜，它是一種格式 —— 需要一個 reader 才能渲染成漂亮的樣子
- 完全等同 PDF：沒有 PDF reader，PDF 也是天書；有 reader 才漂亮
- Google Doc 也能直接貼 markdown，自動整理成漂亮格式
- 醫師團隊不用懂原理，記一句話就好：「請你輸出 HTML 格式讓我看」
- HTML 用瀏覽器一開就是漂亮報表 —— 瀏覽器就是天生最好的 reader

## 互動示範構想

同一份報表、三種輸出並排：左邊「原始 markdown」（滿滿井字號星號的天書）、中間「markdown + reader」（渲染後變整齊）、右邊「HTML」（瀏覽器直接開、有顏色有表格的漂亮報表）。使用者按一個切換鍵，看同一份內容在三種呈現之間跳，親身體會「內容一樣，差的只是有沒有被 reader 打開」。可加一個「PDF / PDF reader」的類比小卡並排，強化「格式 vs 閱讀器」的觀念。

## 課堂提問

- 你以前看到 AI 輸出一堆井字號星號，都怎麼反應？現在你知道那不是壞掉了嗎？
- Markdown 和 PDF 為什麼是同一回事？「reader」在中間扮演什麼角色？
- 哪些日常報表，你其實只要加一句「輸出 HTML 給我看」就能直接拿去用？
