## 一句話

ChatGPT、Cowork、Claude Code、龍蝦，背後可能是同一顆大腦 —— 差別不在腦子，在你給了它多大的身體。

## 三分鐘講稿

學員最常問我的問題就是：「這麼多產品，ChatGPT、Cowork、Claude Code、OpenClaw…我到底該用哪個？」

答案是：先搞懂它們的差別在哪。這些產品，背後可能都是同一顆大腦 —— 同一個模型。**真正的差別，是這顆大腦被裝進了多大的身體、拿到了多少工具、能碰到你哪些東西。** 我幫你排成一張表，從最保守到最開放：

**第一種，ChatGPT / Claude 網頁版。** 這是純聊天，加上少量內建工具，比如 web search。它能做的事就到這裡 —— 而且它**只能動它們那端的電腦**，碰不到你的任何檔案。最安全，但也最受限。

**第二種，Cowork。** 我直接講白：**它就是一個 agent，只是行銷幫它取了個好聽的名字。** 它有有限度的工具、介面做得漂亮，而且已經可以寫東西到你的電腦了。比純聊天多一截。

**第三種，Claude Code。** 這是正式的 agent，工具最多，可以**控制你整台電腦** —— 開 terminal、跑指令、讀寫檔案。威力最大，因為它幾乎什麼都能碰。

**第四種，OpenClaw，就是那隻龍蝦。** 它是常駐型的 agent，權限全開，而且**記憶全都在你這端**，一直幫你待命。

喔對，還有 Manus 之類的，本質上**也都是 agent**。你只要看懂「它有多大的身體、能碰你多少東西」，任何一個新產品出來，你都能一眼歸類。

所以下次選工具，別再問「哪個最厲害」。要問的是：**這件事，我需要多大的身體？** 只是查資料、寫個文案，網頁版就夠了；要它動我電腦裡的檔案、跑一整套流程，才需要 Claude Code 或龍蝦。腦子都一樣強，身體給對了，事情才做得成。

## 關鍵重點

- 同一顆大腦（模型），可以裝進不同的身體；差別在工具多寡與能碰到你多少東西
- ChatGPT / Claude 網頁：純聊天＋少量內建工具（web search），只能動服務商那端
- Cowork：就是 agent，行銷取了好聽的名字 —— 有限度工具、介面漂亮、能寫到你電腦
- Claude Code：正式 agent，工具最多，控制你整台電腦、有 terminal
- OpenClaw 龍蝦：常駐 agent，權限全開、記憶全在你這端；Manus 之類也都是 agent
- 選工具的問法：不是「哪個最厲害」，而是「這件事需要多大的身體」

## 互動示範構想

一張四欄產品對照互動表（ChatGPT 網頁 / Cowork / Claude Code / OpenClaw 龍蝦），每欄標示「本質」與「工具/權限」。核心互動：使用者輸入同一句任務（例如「把這份自費表核對後存成報表」），按執行後看四個產品各自能走到哪一步 —— 網頁版止步於「只能聊、給你步驟」、Cowork「幫你寫出檔案」、Claude Code「開 terminal 跑完整流程」、龍蝦「常駐並記住結果待命」。用同一句話、四種結局，讓學員秒懂「身體大小」的差異。

## 課堂提問

- 你手上正在用的 AI 產品，屬於這張表的哪一格？它能碰到你的檔案嗎？
- 有沒有哪件事，你一直用網頁版硬做、其實該換成能「動你電腦」的 agent？
- 「同一顆大腦、不同身體」這個框架，能幫你怎麼看待下一個新出的 AI 產品？
