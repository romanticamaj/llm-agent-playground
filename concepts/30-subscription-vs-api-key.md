## 一句話

你以為只有一個帳戶，其實有兩個完全不同的錢包 —— 而自動化，只吃得下其中一個。

## 三分鐘講稿

大家每個月都在付錢給 AI，但很少人真的搞清楚一件事：**你付出去的錢，其實分成兩個完全不同的錢包**，而且它們之間不互通。

第一個錢包叫**訂閱制**。每個月固定金額 —— 20 塊、100 塊、200 塊美金，看你買哪一階。它有額度上限，用超過就等下個月重置。重點是：它是設計給誰用的？**給「人坐在對話框前面」用的。** 你打開 Claude Code，打幾行字問它問題、看它回、再問下一句 —— 這整條路吃的都是訂閱。

第二個錢包叫 **API key**。它不包月，它是**按 token 計費**：你儲值一筆錢進去，跑一次扣一次，像儲值玩電動一樣，餘額看得見地往下掉。這個錢包設計給誰？**給「程式自己跑」用的。** 你寫一支腳本半夜自動跑、你排一個每週一早上自動撈信的流程 —— 那不是人在打字，是程式在發請求，吃的就是 API key。像 Replicate 這類服務商，本質上就是在賣打包好的 API key，讓你把自動化流程接上去。

然後就會撞到那個**斷點**。很多人學到第三方常駐 agent —— 就是那隻 OpenClaw 龍蝦 —— 就會想：「我有訂閱啊，讓龍蝦幫我跑就好。」**不行。第三方 agent 吃不到你的訂閱，它只能吃 API key。** 你去查技術原因會查不到，因為**這不是技術問題，是商業問題**：Claude 不想賣這個東西說「給你吃 200 塊美金用到爽」，它要你每一次發詢問就吃我 token。就這麼簡單。

那為什麼你會聽說「某某工具現在可以繞著訂閱用」？有，確實有。但你要看清楚那是什麼性質 —— **那是在鑽漏洞，不是架構**。現在能鑽，是因為廠商還在搶市占率、暫時容忍。Claude 六月十九號就宣布過要全面封鎖，後來怕市占被搶走又縮回去。**它們要封隨時可以封掉。** 所以我的建議很直接：紅利你可以享受，但**不要把「現在能鑽」寫進你的系統假設裡** —— 哪天封了，你整套自動化直接停擺。

最後補一個學員最常混的點：**不是所有 API key 都吃 token。** Gmail 的 API key、Google Calendar 的 API key，那種只是**身分憑證** —— 證明「是我，我有權限讀這個信箱」。它不生產內容，所以不計費，你怎麼呼叫都是零元，我叫它例行公事型。會按 token 收錢的是 **Claude、OpenAI 這種「生產內容」的 API**：它要動模型、燒 GPU，才收你錢。一個是刷門禁卡，一個是叫工人幹活 —— 名字都叫 API key，帳單天差地遠。

心法給你一句話。以後每次要決定用哪個錢包，就問自己：**「這件事跑的時候，我人在不在？」** 人坐在對話框前面、一句一句跟它來回 —— 訂閱就夠了。無人排程、通宵跑、第三方 agent 代你跑 —— 準備 API key，而且要有心理準備：**這是按量計費，它會真的燒錢。**

## 關鍵重點

- 訂閱制＝固定月費（20/100/200 美金）＋額度上限＋每月重置，設計給「人坐在對話框前面」用
- API key＝按 token 計費、儲值扣款，設計給「程式自己跑」用；Replicate 這類服務就是在賣打包好的 API key
- 第三方常駐 agent（OpenClaw 龍蝦）**吃不到訂閱**，只能吃 API key —— 原因不是技術，是商業
- 現在有些第三方繞得過去，那是**在鑽漏洞**，廠商搶市占暫時容忍；隨時可以封，別寫進你的系統假設
- 不是所有 API key 都計費：Gmail 這種只是**身分憑證**（例行公事型，$0）；Claude/OpenAI 這種**生產內容**才按 token 收錢
- 判斷法則：**「這件事跑的時候，我人在不在？」** 人在 → 訂閱夠用；人不在 → 準備 API key 並準備燒錢

## 互動示範構想

畫面上兩個錢包並排：左邊「訂閱制」是一條固定額度條（$200/月、有上限、每月重置），右邊「API key」是一個儲值餘額（$50.00，用多少扣多少）。上方一排任務卡片：`我在對話框問問題` / `排程每週自動撈信` / `第三方 agent 通宵跑` / `Gmail 抓附件`。使用者選一張卡、再點一個錢包丟進去，看它被接住還是被彈回來。

導演節奏：先丟「我在對話框問問題」到訂閱 —— 接住，額度扣一格；再丟「第三方 agent 通宵跑」到訂閱 —— **被彈回來、蓋上拒絕章**（戲劇高潮：不是技術，是商業）；同一張卡改丟 API key —— 接住了，但餘額真的往下掉；接著丟 Gmail —— 一樣進 API key，帳單卻是 $0.00（身分憑證，不生產內容）。最後演「側門」：畫面上出現一道虛線側門讓第三方繞進訂閱，玩幾秒後**閘門喀一聲關上**、剛剛鑽進去的任務被踢出來 —— 收在「它們要封隨時可以封掉」。sandbox 讓學員自由組合四張卡 × 兩個錢包，還能自己按下「廠商封鎖側門」，並把訂閱額度用到滿看它拒收。

## 課堂提問

- 你現在手上跑的自動化流程，如果第三方明天就封鎖訂閱繞道，哪一條會直接停擺？
- 你手上這幾把 API key，哪些是「身分憑證」、哪些是「按 token 計費」？分得出來嗎？
- 「這件事跑的時候，我人在不在？」—— 用這句話重新檢查你這週想做的三件事，各自該用哪個錢包？
