## 一句話

**目的地決定格式** —— 東西要往哪裡去，就決定它該長什麼樣：要給人看就輸出 HTML、要進 Excel 就要 TSV、要貼文件就用 Markdown、要貼 LINE 就純文字、要進日曆就 .ics、要給系統就 JSON。

## 三分鐘講稿

你有沒有遇過，叫 AI 幫你整理一份報表，結果它吐給你一堆長這樣的東西：井字號、星號、一槓一槓的表格線…你看了頭很痛，覺得「這什麼鬼，好醜」。

那個東西叫 **markdown**。我要幫它平反一下 —— **markdown 不醜，它只是一種格式，你需要一個 reader 才能把它變漂亮。**

這件事跟 PDF 一模一樣。你想想，一個 PDF 檔本身也是一堆看不懂的編碼，你之所以覺得 PDF 很整齊漂亮，是因為你用 **PDF reader** 打開它。沒有 reader，PDF 也是天書。Markdown 也是同樣的道理 —— 它需要一個 markdown reader 幫你「渲染」出來，才會變成漂亮的標題、清單、表格。順帶一提，很多地方其實已經內建這種 reader 了，比如 **Google Doc**，你把 markdown 直接貼進去，它會自動幫你整理成漂亮的格式。

但我知道，對醫師團隊來說，你根本不想搞懂什麼 reader、什麼渲染。沒關係，你只要記住一句話就好，這句話解決一切：**「請你輸出 HTML 格式讓我看。」** 為什麼是 HTML？因為你的瀏覽器天生就是最好的 reader。AI 輸出 HTML，你用瀏覽器一開，直接就是漂亮的排版、表格、顏色 —— 不用裝任何東西、不用懂任何技術。一句話，天書變報表。而且瀏覽器一按列印，它就變成 PDF 了。

不過，HTML 不是唯一的答案。這裡有一個更大的原則，記住它，你就再也不會為格式煩惱 —— **目的地決定格式**。這份東西「要往哪裡去」，就決定它該長什麼樣。要給人看，輸出 HTML；那如果不是要給人看呢？

舉幾個真正的神技。第一個：**TSV**。你叫 AI 用「Tab 分隔」把一張表格輸出出來，複製起來，直接貼進 Excel —— 它會**自動分欄**，每一格乖乖跳進對應的格子裡，你完全不用手動切。這招用過的人都回不去了。第二個：**.ics**。你叫 AI 把一份行程輸出成 .ics 檔，點兩下，它就自動匯進你的 Google 日曆或 Outlook，變成一格一格的行事曆事件。還有 **公文格式**（函：主旨／說明／辦法，AI 直接套好模板）、**SRT 字幕**（影片要上字幕，就要這個格式，帶時間碼）。

所以你要的不是「一個萬用格式」，而是先問自己一句：**這東西要去哪裡？** 要進 Excel 就要 TSV、要貼 LINE 就純文字（不跑版）、要貼 Notion 或 Google Doc 就 Markdown、要進日曆就 .ics、要給系統或自動化就 JSON、要畫流程圖就 Mermaid。想清楚目的地，格式自然就有了答案。

## 關鍵重點

- 核心原則：**目的地決定格式** —— 先問「這東西要去哪裡」，格式就有了答案
- 給人看 → **HTML**（瀏覽器天生就是 reader，一開就漂亮，一按列印就是 PDF）
- 進 Excel → **TSV**（Tab 分隔，複製直接貼 Excel 會自動分欄，神技）；一般匯入用 CSV
- 貼文件 → **Markdown**（貼 Notion／Google Doc 自動變漂亮）；貼 LINE／Email → **純文字**（不跑版）
- 進日曆 → **.ics**（點兩下匯進 Google／Outlook）；聯絡人批次匯入 → vCard
- 給系統／自動化 → **JSON**；舊系統／申報 → XML；要公式回去用 → 直接要 Excel 公式
- 其他好用格式：Mermaid（流程圖／甘特圖）、SVG（可放大的圖）、簡報大綱（貼 Gamma／Marp）、公文（函：主旨／說明／辦法）、SRT（影片字幕）、雙語對照表
- Markdown 不是醜，它只是還沒被 reader 打開 —— 完全等同 PDF 需要 PDF reader

## 互動示範構想

**目的地選擇器**：畫面中央一份固定的範例資料（診所下週排班／費用明細）。前段先用三分頁重溫「原始 markdown 天書 → reader 渲染 → 請你輸出 HTML」的核心對比，並帶出「瀏覽器就是 reader，列印即 PDF」。接著原則登場：**目的地決定格式**，六個目的地圖示（Excel／LINE／文件／日曆／系統／字幕）環繞。亮點示範：同一份排班資料自動變身兩個神技 —— TSV（模擬貼進 Excel 格子自動分欄的動畫）與 .ics（模擬匯入日曆變成一格格行事曆事件）。最後 sandbox 是一個目的地選擇器：玩家點 8 個目的地按鈕（Excel／LINE／文件／列印／日曆／系統／字幕／簡報），右側即時顯示對應格式的輸出預覽，並附上一句可直接複製的「prompt 關鍵句」，讓使用者親身體會「同一份內容，換個目的地就換個格式」。
