## 一句話

Agent 沒有開關，只有文字接龍 —— 有開關的是排程，不是 Agent。

## 三分鐘講稿

很多人不敢用 Agent，理由都很像：「我怕它在背後偷偷跑。」怕它半夜自己去改我的檔案、自己寄信出去、自己燒我的 token。

我先把結論講死：**Agent 本身沒有開關的概念，只有文字接龍。** 沒有觸發事件，它就不會主動做事。

回想最原始的樣子。你打開聊天視窗，你不講話，它會自己跳出來找你聊嗎？不會。它就坐在那裡，等你送一句話進去，接一段龍給你，接完就停。Agent 只是這件事的加強版 —— 中間多了幾十輪工具呼叫，但本質沒變：**有輸入才有輸出，做完就停。** 它不是一隻住在你電腦裡的生物，它是一台接龍引擎。

所以「怎麼讓 Agent 停下來」這題，答案樸素到有點好笑：**直接關掉 Claude，或者關機就好 —— 機器沒開，Agent 就不能接龍。**

那問題來了。為什麼有些 Agent 看起來真的會自己動？早上起來信箱就整理好了，那總不是我做的吧？

因為**有人另外給了它節奏**。那個東西叫**排程**。

網頁版 Claude 裡它叫 **Schedule**。你去 Home，左邊有個 Scheduled 頁面，點進去就看得到你到底建了哪些排程 —— 比如「每天幫我整理 Gmail」。重點在這裡：**那一列右邊有一個 toggle 開關**，你把它撥掉，這件事就再也不會發生。Code 版的叫 **Routine**，邏輯一模一樣、功能更完整、指令複雜一點；關掉 Routine，一樣不再觸發。

這是整堂課最重要的一句話：**有開關的是排程，不是 Agent。**

Agent 是被動的接龍引擎，排程是那隻按下播放鍵的手。搞混這兩件事，你就會以為 Agent 是一個常駐在背景的生物，然後開始怕它。它不是。它連「待命」都算不上 —— 沒被叫到的時候，它根本沒在跑。

想通這件事，四個很實際的問題同時被解掉。

**怕它亂跑？** 你要找的不是 Agent 的開關 —— 沒有那種東西。你該去翻的是**排程清單**：現在有哪幾條排程開著？誰建的？多久跑一次？

**它怎麼都不動？** 先別急著怪它笨，先問一句：**是不是根本沒有觸發事件？** 很多人以為 Agent 建好就會自己跑起來 —— 不會。它會安安靜靜躺在那裡，等一個永遠不會來的訊號。

**要它動？** 你得明確給它節奏。我們課堂上做 MSK Radar，那個掃 PubMed 新文獻的雷達，就刻意**只給任務、不給節奏**：「做什麼」寫在 Agent 裡，「多久做一次」交給 Routine 或 Schedule。這兩件事該分開 —— 改任務不會動到節奏，改節奏也不用重寫任務。

**要它停？** 關排程，或者關機。機器沒開就接不了龍。

最後把這三堂串起來，這是一組完整的**Agent 邊界三問**。**概念 20 問「它拿多大的鑰匙」** —— connector、MCP、還是 API key。**概念 23 問「它在哪裡跑」** —— 雲端 sandbox 還是你的機器，開了哪幾個口。**這一堂問「它什麼時候跑」** —— 誰在給節奏，那個開關在哪裡。

拿多大的鑰匙、在哪裡跑、什麼時候跑。三個問完，你才真的知道這隻 Agent 的邊界在哪。

## 關鍵重點

- Agent 本身沒有開關，只有文字接龍 —— 沒有觸發事件就不會主動做事，它跟聊天視窗一樣是被動的
- 「做完就停」不是「待機」：沒被叫到的時候，它根本沒在跑，不是在背景守著
- 有些 Agent 看起來會自己動，是因為**有人另外給了它節奏** —— 網頁版叫 Schedule（Home → Scheduled 頁面，每條排程右邊有 toggle 可停用），Code 版叫 Routine（邏輯相同、功能更完整、指令較複雜）
- **有開關的是排程，不是 Agent** —— Agent 是被動的接龍引擎，排程是那隻按下播放鍵的手
- 怕它亂跑，就去翻排程清單；它不動，先問有沒有觸發事件；要它停，關排程或關機
- 任務與節奏要分開寫：MSK Radar 只給任務不給節奏，節奏交給 Routine／Schedule
- Agent 邊界三問：概念 20「拿多大的鑰匙」、概念 23「在哪裡跑」、這篇「什麼時候跑」

## 互動示範構想

一台「接龍引擎」＋一條事件時間軸。畫面中間是機器（執行環境）的框，框裡左邊是 Agent 引擎卡（一排 token 格子、狀態燈寫「靜止 · 沒有進程」，刻意不寫「待命」），右邊是兩個開關並排；框下方是一條會有播放頭來回掃的時間軸。

導演節奏：先看引擎 —— 時間軸上什麼都沒有，token 格子全暗，狀態是靜止，浮出一句「它不是在待命，是根本沒在跑」→ 按「送一句話進去」，時間軸上落下一個觸發點，播放頭掃到它，引擎醒來、token 一格一格點亮接完龍、輸出一行結果，**然後整排熄回去、狀態回到靜止**（做完就停）→ 打開排程，時間軸上長出等距的週期觸發點，播放頭每掃到一個，引擎就醒一次、做完再停 → **關鍵一拍**：鏡頭推到那兩個開關，左邊標「Agent 的開關」是一個空插槽、劃著叉、按下去只會抖動並浮出「沒有這個東西」；右邊標「排程的開關」是真的可以撥的 toggle，撥掉 → 時間軸上的觸發點一個個消失，播放頭再怎麼掃，引擎都不再醒來 → 再一拍按「關機」，整個機器框變暗、播放頭停住，連排程也觸發不了（呼應概念 23）→ 最後 sandbox：自由送訊息、開關排程、調整排程頻率、關機重開，還可以親手去按那個不存在的 Agent 開關。

## 課堂提問

- 你現在最怕哪個 Agent「在背後偷偷跑」？如果去翻排程清單，它上面到底有沒有東西？
- 你建好卻「一直沒動」的那個 Agent，是它壞了，還是根本沒人給它觸發事件？
- 為什麼「任務」和「節奏」要分開寫在兩個地方？合在一起會有什麼麻煩？
