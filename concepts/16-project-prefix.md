## 一句話

GPTs、Gem、Project 聽起來很高級，其實只是被固定寫在文字接龍最前面的那一段話。

## 三分鐘講稿

很多人被這些名字唬住了 —— OpenAI 叫它 GPTs、Google 叫它 Gem、Anthropic 叫它 Project。聽起來各家都有一套神秘的技術。我跟你講白：**它們只是行銷名字，本質就是把一段話，接在你文字接龍的最前面。** 就這麼簡單。

還記得我們第一課講的嗎？AI 是文字接龍，每個字都是前面那串字的延伸。那「Project」在做的事情，就是幫你把一段固定的開頭鎖在最前面，每次聊天都自動接上。

所以你每一次跟這個 Project 對話，AI 真正拿到的，是三塊東西拼在一起：

第一塊，**記憶的接龍** —— 它記得的關於你的事、之前設定過的偏好。
第二塊，**Project 的起始點** —— 你幫這個 Project 寫好的那段固定開頭，比如「你是我的社群文章寫手」。
第三塊，**你這次要聊的內容** —— 當下輸入的那句話。

這三塊接在一起，餵進文字接龍，長出結果。因為它是非決定性的，所以每次不會一模一樣 —— 但因為前面兩塊固定住了，所以風格會穩定地往同一個方向長。

舉個實際的：我做一個「社群寫手」的 Project，開頭就寫「你是社群文章寫手，會用我的 skill 來撰寫貼文」。之後我每次只要丟主題進去，它就用固定的語氣幫我寫。而且這裡有個關鍵 —— **你那段開頭 prompt 寫得越細，每個月產出的風格就越穩定。** 你今天多花十分鐘把「我要的語氣、我不要的口頭禪、我的目標讀者」寫清楚，換來的是接下來幾百篇貼文都對得上你的調性。

所以下次有人跟你炫耀他做了個很厲害的 GPTs，你心裡要清楚：他不過是寫了一段好的開頭，鎖在接龍的最前面而已。而你，也做得到。

## 關鍵重點

- GPTs / Gem / Project 只是行銷名字，本質 = 固定寫在文字接龍最前面的一段開頭
- 每次對話 AI 真正拿到的是三塊拼裝：①記憶的接龍 ②Project 起始點 ③你這次的輸入
- 三塊接起來 → 非決定性輸出，但前兩塊固定住 → 風格穩定往同方向長
- 起始點 prompt 寫越細，每月產出的風格越穩定（例：社群寫手 Project）
- 這是第一課「文字接龍」的直接延伸 —— 沒有神秘技術

## 互動示範構想

一個「三段式 context 組裝」的視覺：畫面上三塊積木由上到下疊 —— 記憶塊、Project 起始點塊、當前輸入塊 —— 接成一長條餵進右邊的接龍引擎，吐出一段文字。使用者可以編輯「Project 起始點」那一塊（例如把「正式老派」改成「輕鬆網路梗」），保持「當前輸入」那句不變，即時看到右邊輸出的風格整個換掉 —— 親手體會「固定開頭決定整體風格」。

## 課堂提問

- 你用過的 GPTs / Project，如果拆開看，它的「固定開頭」大概寫了什麼？
- 為什麼把起始點 prompt 寫得更細，會讓每個月的產出更穩定？
- 「記憶塊 + 起始點 + 當前輸入」三塊，哪一塊是你最能掌控、也最該花時間的？
